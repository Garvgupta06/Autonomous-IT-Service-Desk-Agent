# Windows Troubleshooting Runbook

**Category:** Windows Support
**Document Type:** Troubleshooting Runbook
**Intended Use:** Autonomous IT Service Desk Agent

## 1. Windows Performance Problems

### Symptoms

* Windows starts slowly.
* Applications respond slowly.
* The computer freezes or becomes unresponsive.

### Troubleshooting Steps

1. Ask the user when the problem started and whether it affects all applications or only one.
2. Check whether multiple applications are consuming excessive CPU or memory using Task Manager.
3. Close unnecessary applications, after saving any work.
4. Check available disk space.
5. Restart the affected application.
6. If the issue continues, restart the computer when it is safe to do so.
7. Record error messages and escalate persistent problems to IT support.

### Safety

Do not terminate unfamiliar system processes or delete system files without authorization.

## 2. Windows Update Problems

### Symptoms

* Updates fail to install.
* Windows Update repeatedly displays an error.
* Updates remain pending.

### Troubleshooting Steps

1. Record the exact error message or error code.
2. Check that the computer has a working internet connection.
3. Confirm that sufficient disk space is available.
4. Restart the computer if a restart is pending and it is safe to do so.
5. Retry the update using the organization's approved procedure.
6. If the problem persists, escalate to IT support with the error code and troubleshooting steps already attempted.

### Safety

Do not disable security software or install unofficial system updates to bypass an error.

## 3. General Windows Troubleshooting

### Initial Checks

1. Ask the user to describe the problem and when it began.
2. Determine whether the issue affects one application, one user, or the entire computer.
3. Record any error messages.
4. Check whether the problem started after a recent update or configuration change.
5. Try only approved, reversible troubleshooting steps.
6. Document the results of each step.

### Escalation

Escalate issues that persist after basic troubleshooting, involve suspected hardware failure, or require administrator privileges.
