# VPN Connection Troubleshooting

**Category:** Networking
**Issue:** VPN Connection Failure

## Symptoms

* The VPN client cannot connect.
* The VPN disconnects repeatedly.
* Internal resources are inaccessible while the VPN is connected.

## Troubleshooting Steps

1. Check whether the device has a working internet connection.
2. Verify that the user is using the approved VPN client.
3. Record the exact VPN error message or error code.
4. Check whether the VPN service is experiencing an outage.
5. Confirm that the user's account is authorized to use the VPN.
6. Retry the connection using the organization's approved procedure.
7. If the problem persists, escalate to the network support team with the error details.

## Safety

* Never ask users to share their passwords or MFA codes.
* Do not disable security controls to bypass a VPN problem.
* Do not modify VPN server settings without authorization.

## Escalation

Escalate repeated connection failures, authentication errors, or suspected VPN service outages to the network support team.
